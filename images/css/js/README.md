## Project Overview
This project is a professional website for Hope Haven Animal Rescue, a non-profit organisation dedicated to rescuing and rehabilitating abandoned animals. The website aims to raise awareness, attract volunteers and donors, and provide clear information about adoption and services.

## Website Goals and Objectives
- Increase awareness of Hope Haven's mission.
- Attract more volunteers and donors.
- Showcase available animals for adoption.
- Provide easy access to services.
- Encourage community engagement.

## Key Features and Functionality
- 5-page responsive website (Home, About, Services, Enquiry, Contact).
- Consistent navigation menu across all pages.
- Enquiry/volunteer application form.
- Contact form.
- Embedded Google Maps showing two locations (Johannesburg and Pretoria).
- SEO-friendly HTML structure.
